About this project

This project is a bot for Kuhn and Texas Hold'em poker variants. It uses Counterfactual Regret Minimization and abstraction of the game to compute a strategy.

Kuhn variant is fully functional. I am currently working on the front end of the Texas Variant. It will be completed before October 2024.
